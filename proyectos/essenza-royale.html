Essenza Royale

Plataforma e-commerce para la venta de perfumes desarrollada con Laravel, React y PostgreSQL (Neon).

Permite a los clientes explorar un catálogo de perfumes, buscar y seleccionar las variantes disponibles, consultar el historial de compras y realizar pagos mediante integración con Mercado Pago.

Por su parte, los administradores cuentan con un panel de gestión para administrar productos, descuentos, stock y ventas.

ReactLaravelPostgreSQL

Funcionalidades principales

Backend

  • Gestión de perfumes y variantes desde panel administrativo.
  • Control de stock y actualización automática durante las compras.
  • Registro de ventas y detalle de productos vendidos.
  • Administración y notificaciones sobre descuentos.
  • API REST desarrollada en Laravel.

Frontend

  • Catálogo de perfumes con imágenes, descripciones y variantes por volumen.
  • Carrito de compras con actualización dinámica de cantidades y totales.
  • Aplicación automática de descuentos y promociones.
  • Consulta del historial de compras.
  • Integración con Mercado Pago.
  • Diseño responsive.

Infraestructura

  • Aplicación desplegada en Vercel.
  • Base de datos PostgreSQL alojada en Neon.
  • Arquitectura desacoplada entre frontend, backend y base de datos.
